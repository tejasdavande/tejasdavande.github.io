## Tech
- HTML5 / CSS3 (responsive, mobile nav)
- Vanilla JavaScript (page transitions, animated counters)
- [AOS](https://github.com/michalsnik/aos) — scroll animations
- [Vanta.js](https://www.vantajs.com/) + Three.js — animated hero background
- [animate.css](https://animate.style/) — micro animations

## Local preview
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
